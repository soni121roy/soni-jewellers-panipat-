# 💎 Soni Jewellers Panipat - Luxury E-commerce

**Live Demo:** https://soni-jewellers-panipat.vercel.app
**Built by Soni Roy | Panipat, Haryana | Open to Frontend Roles**

A real-world e-commerce platform built for a local jewellery brand in Panipat. Not a tutorial project — made for actual customers.

![Next.js](https://img.shields.io/badge/Next.js-14-black)![Tailwind](https://img.shields.io/badge/Tailwind-CSS-38B2AC)![TypeScript](https://img.shields.io/badge/TypeScript-91.9%25-blue)

### ✨ Why This Project?
Local jewellers in Panipat still use WhatsApp catalogs. I built them a modern, fast, mobile-first store with an admin panel so they can add products themselves without a developer.

### 🔥 Features
- **4 Smart Tabs:** 22KT Gold, Bridal Sets, Temple Jewellery, Daily Wear - Instant filtering
- **Custom Admin CMS:** `/admin` - Add product with images, price, MRP, category - No backend needed
- **Hide Defaults:** One click to hide dummy products, show only your own
- **Real Business Logic:** Price, MRP strikethrough, WhatsApp Enquiry
- **Mobile First:** Built for Panipat customers who shop on phone

### 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Storage:** LocalStorage CMS (zero cost for small business)
- **Future:** Razorpay, MongoDB
